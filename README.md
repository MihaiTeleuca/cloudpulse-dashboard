# CloudPulse Dashboard

Professional **frontend-only cloud operations dashboard demo** for Mihai Teleuca's portfolio.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Custom Canvas charts
- Browser localStorage
- No framework
- No database
- No backend
- No API keys

## Included features
- Responsive operations dashboard
- Simulated live CPU, RAM and latency metrics
- Custom performance charts
- Cloud resource inventory with search/filter
- AWS / Azure / GCP / Cloudflare demo resources
- Infrastructure topology
- Regional latency monitoring
- FinOps cost dashboard
- Budget and optimization recommendations
- Incident queue
- Create and resolve demo incidents
- Searchable activity/audit logs
- Notifications drawer
- Dark/light mode
- Compact mode
- CSV report export
- Local preferences saved in the browser

## Publish on GitHub Pages
1. Create a new repository, for example `cloudpulse-dashboard`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Choose **main** and **/(root)**.
7. Save.

Your URL will look like:

`https://YOUR-USERNAME.github.io/cloudpulse-dashboard/`

## Important
All telemetry, cloud resources, incidents and costs are intentionally simulated. The project is safe for a public portfolio because it contains no secrets, credentials, database connection or cloud account access.

## Portfolio description
CloudPulse is a frontend cloud operations dashboard that simulates real-world infrastructure monitoring, observability, FinOps and incident-management workflows. It includes live telemetry, resource inventory, cost optimization, incident handling, audit logs, local preferences and CSV reporting without requiring a backend or database.
